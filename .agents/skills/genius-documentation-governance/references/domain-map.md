# Mapa de domínios

Use domínios como lentes, não como novas fontes de verdade.

| Domínio | Pistas de documentação/código |
|---|---|
| analytics | `analytics`, dashboards, métricas, views/RPCs de leitura |
| knowledge | artigos, editor, publicação, help center |
| support | tickets, fila, conversas, SLA |
| customer-success | carteira, clientes, saúde, owners |
| settings/access/tenancy | permissões, memberships, RLS, telas administrativas |
| integrations/hubspot/omie | Edge Functions, sync, cache, watermark, reconciliação |
| security | auth, grants, policies, secrets, auditoria |
| navigation/public-help/editor | rotas, manifestos, shell, temas e conteúdo público |
| release/architecture | estado, roadmap, contratos e critérios de publicação |

Para cada domínio mapear finalidade, rotas, telas, navegação, backend, contratos, docs, testes, status de release, dependências, owners e riscos.
