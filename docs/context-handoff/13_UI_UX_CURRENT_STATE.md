# UI/UX Current State

## Diagnóstico geral

Há evolução visual recente, mas o sistema ainda não se comporta como uma experiência única. O dashboard e a central pública estão mais consistentes; outras áreas internas apresentam diferenças fortes de layout, densidade, componentes, filtros, colunas e prioridades visuais.

## Evidências visuais incluídas

- Central pública home.
- Página de artigo.
- Dashboard gerencial.
- Clientes B2B.
- Carteira CS.
- Contas B2B admin.
- Acessos/admin.

## Problemas recorrentes

- Listas ocupando espaço excessivo enquanto detalhes importantes ficam comprimidos.
- Filtros e tabs com padrões diferentes entre telas.
- Sidebar ainda pode crescer demais para operação diária.
- Cards repetidos ou com baixa ação operacional.
- Telas com sensação de módulo isolado, não de plataforma coesa.
- Alguns textos apresentam problemas de encoding em dados legados.

## Direção de design

- Padronizar tokens, spacing, estados, botões, filtros e tabelas.
- Priorizar conteúdo acionável.
- Usar o mascote Genius em estados de loading, vazio e sucesso, sem excesso de animação.
- Evitar estética genérica de IA; transmitir tecnologia operacional, clareza e confiança.

## Recomendação

Não fazer redesign amplo antes da decisão de MVP. Se o release urgente for Dashboard + Central, concentrar QA/polimento nessas duas superfícies e esconder ou restringir módulos internos incompletos.
