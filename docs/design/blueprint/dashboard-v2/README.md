# Dashboard Blueprint System V2

Blueprints documentais e visuais para revisão do Dashboard Gerencial.

Este diretório não é uma implementação de runtime. Cada SVG é uma prancha
standalone em 1600×1000, com shell, hierarquia, estados e regras de leitura
para uma superfície específica.

## Inventário

1. Visão Geral
2. Comercial
3. Customer Success
4. Suporte & Chat
5. Financeiro
6. Integrações
7. Fontes do Dashboard
8. Histórico de sincronizações
9. UI-05 — Gênio em ação
10. Gênio loading
11. Guia de princípios visuais

## Verificação

- KPIs lideram a leitura curta; séries temporais são subordinadas ao recorte.
- Períodos longos usam semanal/mensal/trimestral, nunca granularidade diária
  ornamental.
- Dados conceituais usam `—`, `Indisponível` ou `Conceitual`; não há números de
  produção inventados.
- O Gênio é avatar técnico de forma definida, sem fantasma, espírito ou dado.
- As imagens renderizadas e o manifesto ficam no pacote externo de revisão.
