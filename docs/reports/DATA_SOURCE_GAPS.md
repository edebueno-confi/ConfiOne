# Lacunas de fontes executivas — MVP-UX-02

## Bloqueios de fonte, não de interface

1. Produto não possui fonte operacional ou contrato de ingestão confirmado.
2. Desenvolvimento não possui fonte operacional ou contrato de ingestão confirmado.
3. Customer Success possui carteira e atribuição, mas não possui fonte confiável para health score, renovação, churn, expansão ou NPS.
4. HubSpot não entrega no read model atual conversas, inbox, atividades, associações completas, CSAT ou NPS.
5. OMIE não tem no contrato atual previsão, centros de custo, cancelamentos e histórico de alterações.

## Próxima decisão

Antes de criar novos KPIs, definir fonte, propriedade, periodicidade, escopo tenant, política de retenção, estado de frescor e contrato de read model. O painel deve continuar sinalizando a lacuna até essa decisão.
